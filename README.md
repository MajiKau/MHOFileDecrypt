# MHOFileConverter
A Tool for decrypting and converting specific files from MHO IFS to XML and the reverse.
The files inside MHO IFS have the .xml extension but are actually encrypted CryXmlB binary files.

## Usage
`MHOFileConverter.exe <encrypted file path OR xml file path>`

## Credit
This tool is based on https://github.com/Andoryuuta/MHOFileDecrypt which includes a slightly modified copy of https://github.com/Bl00drav3n/CryXmlB for converting binary XML files to regular XML.
